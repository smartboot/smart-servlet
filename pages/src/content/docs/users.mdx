<TabItem label="关于开源协议">

自 v3.4 起，smart-servlet 采用 **Apache License 2.0**，企业可免费用于生产与商业场景，无需采购使用授权。

- 允许商用、修改、再分发、嵌入闭源产品、提供托管服务
- 无并发数、部署规模、功能或试用时长限制，所有用户使用同一份代码
- v3.3 及更早版本仍适用发布时的 AGPL-3.0，协议变更不追溯已发布版本
- 商标、官方认证与兼容性标识不属于协议授权范围，使用需书面许可

我们相信：

> 企业愿意付费的，从来不是"允许使用"，而是生产环境出问题时有人负责。

</TabItem>

<TabItem label="服务订阅权益">

企业服务订阅按年度签约，提供的是支持、交付与责任保障，不改变开源协议：

- 专属支持通道与合同约定的响应、解决时效（SLA）
- 生产故障优先处置与远程/现场兜底支持
- 指定版本长期维护、安全补丁与 EOL 提前通知
- JDK / Spring Boot / Jakarta Servlet 大版本升级适配指导
- 代码审计说明、SBOM、兼容性与国产化适配证明等合规材料配合
- 迁移实施、上线前架构评审、压测调优与培训（按人天）
- 服务客户公示、兼容性认证与生态合作机会

订阅不改变软件功能，也不会限制未订阅用户使用任何能力。

## 参与共建

无论是否订阅服务，均可通过以下方式支持项目：

- 在生产环境使用并反馈真实场景的问题与性能数据
- 提交 Issue、文档改进与 Pull Request
- 将 smart-servlet 集成进自己的产品，并反馈兼容性结果
- 作为系统集成商，为终端客户提供部署、迁移与运维服务

如需订阅服务或洽谈生态合作，请通过 [Gitee Issue](https://gitee.com/smartboot/smart-servlet/issues) 联系我们。
